隱私權政策

生效日期：2026 年 10 月 20 日

輕注音是 Ino Chueh 開發的免費、開源注音輸入法（以下稱「我們」）。這份政策說明輕注音會傳送哪些資料、為什麼、怎麼關閉。原始碼公開於 GitHub，可以自行查證。

輸入法本身

輸入法程式不連網。你打的字、選字紀錄都存在你的電腦，可以在「輕注音」App 的「選字紀錄」查看或刪除。

分享新詞（macOS，預設開啟）

為了讓詞庫收進大家常用、但詞庫還沒有的新詞，「輕注音」App 會在背景（大約一天一次）把下面這些資料傳到我們的伺服器：

詞你選過、但詞庫裡沒有的詞。這也包括你一次選出的整串字，例如分段選出「我想」「吃飯」後，記下的「我想吃飯」。
打的注音你為這個詞打的注音，例如 ㄨㄒㄔㄈ。
次數你選過這個詞幾次。
裝置編號App 第一次傳送時隨機產生的一組編號，只用來計算「幾台電腦送過同一個詞」。它不包含、也不連結到你的姓名、帳號、電子郵件或電腦序號。
App 版本例如 3.0。

我們不會收集：你在哪個 App 打字、詞的前後文、你打的其他內容、詞庫已經有的詞、帳號、聯絡資料或位置。

這些詞由我們人工審核，通過的會加進詞庫，隨下一版提供給所有使用者。詞本身會因此公開（詞庫是開源的），但不會附上是誰送出的。

如何關閉：打字教學最後一頁的「分享新詞」勾選框，或「輕注音」App「一般」頁的「分享新詞」開關。關閉後就不會再傳送。

自動更新

「輕注音」App 會定期向 GitHub 查詢有沒有新版本，並從 GitHub 下載。這只會向 GitHub 送出一般的網路請求，不包含你的任何資料；GitHub 的資料處理依 GitHub 隱私權聲明。可以在 App 關閉「自動更新」。

網站

本網站由 Vercel 代管，Vercel 會留存一般的存取紀錄（例如 IP 位址、瀏覽器種類），用於網站運作與安全。我們不使用廣告或追蹤程式碼。

資料的保存與處理

  • 分享的新詞存放在由 Vercel 與 Neon 代管的資料庫，只有我們能登入審核頁查看。
  • 我們不出售、不出租這些資料，也不用於廣告。
  • 資料保存到不再需要為止（例如詞已審核完畢，或停止這項服務）。

你的權利

你可以隨時關閉分享。想要刪除已經傳送、來自你電腦的資料，請寫信到 ino@noky.dev，附上「輕注音」App「一般」頁「分享新詞」說明中顯示的裝置編號，我們會刪除這個編號的所有資料。

政策更新

政策如有更新，會修改本頁並更新生效日期；重大變更會在新版的發布說明中告知。
