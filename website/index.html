輕注音

把 iPhone 注音的簡拼搬到電腦。每個字只打第一個注音，打 ㄋㄏㄇ 就是「你好嗎」。

下載 macOS 版 免費 Windows 版 即將推出

macOS 13 以上，Apple Silicon 與 Intel・開源・不連網

 

打法

ㄋㄏㄇ → 你好嗎

只打第一個注音

不用打完整的音，也不用打聲調。和 iPhone 注音一樣，連打一整句，第一個候選就是整句。

ㄍㄗㄈㄈ → 工作｜ㄈㄈ

可以只選前面

整句不對時，先選前面的「工作」，剩下的 ㄈㄈ 留著，接著再選。不用整串刪掉重打。

ㄋㄧˇㄏㄇ → 你好嗎

完整注音、聲調都能混著打

想打得更精確時，多打幾個符號或加上聲調（3 4 6 7），候選就會縮小。

越用越順手

記住你的選擇

選過的詞下次排到前面，分段選過的整句下次直接出現。紀錄只存在你的電腦裡。

按鍵

鍵盤排列是大千（標準注音）。

空白 Enter送出選中的候選
← → Tab選擇候選
3 4 6 7聲調 ˇ ˋ ˊ ˙（可省略）
Backspace刪掉最後一個注音
Esc清空輸入區
Shift + , . / 1 ;，。？！：
Caps Lock暫時打英文

安裝

  1. 下載 LightBopomofo.dmg 並打開。
  2. 雙擊裡面的「輕注音」，按「安裝」。不需要管理員密碼。
  3. 在選單列的輸入法選單選「輕注音」，就可以開始打字。
  4. 如果選單裡沒有，到「系統設定 → 鍵盤 → 輸入方式」按「＋」，在「繁體中文」底下加入「輕注音」；仍然沒有的話，登出再登入一次。
會不會上傳我打的字？

不會。輕注音完全不連網，所有計算都在你的電腦上完成。你選過的詞記錄在 ~/Library/Application Support/LightBopomofo/history.tsv，只存在本機。

和內建注音、新酷音有什麼不同？

內建注音要打完整的音。輕注音照 iPhone 注音的方式，每個字只打開頭的注音就能選出整個詞，也能整句連打。

怎麼解除安裝？

再打開一次 LightBopomofo.dmg，雙擊「輕注音」，選「解除安裝…」。若也想刪除選字紀錄，刪除 ~/Library/Application Support/LightBopomofo。

怎麼更新？

下載新版的 LightBopomofo.dmg，雙擊「輕注音」，按「更新」。

Windows 版什麼時候出？

正在開發中，會和 macOS 版共用同一個輸入引擎。完成後會放在這個網頁。
