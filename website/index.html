macOS 安裝
  1. 打開 LightBopomofo.dmg，把「輕注音」拖到「應用程式」。
  2. 打開「輕注音」，它會自動安裝並啟用輸入法，不需要管理員密碼。
  3. 在選單列的輸入法選單選「輕注音」。沒看到的話，到「系統設定 → 鍵盤 → 輸入方式」按「＋」，在「繁體中文」底下加入。
Windows 安裝
  1. 執行 LightBopomofo-Setup.exe。安裝檔還沒有程式碼簽署，看到「Windows 已保護您的電腦」時，按「其他資訊」→「仍要執行」。
  2. 照指示安裝（需要管理員權限），裝完會自動加入輸入法清單。
  3. 按 Windows + 空白鍵 切到「輕注音」；單按 Shift 切換中／英。

會上傳我打的字嗎？

輸入法本身不連網，你打的字和選字紀錄都留在你的電腦，可以在「輕注音」App 的「選字紀錄」查看或刪除。macOS 版預設開啟「分享新詞」：App 會把你選過、詞庫還沒有的詞（包括一次選出的整串字）連同打的注音和次數，以一組隨機的裝置編號傳給我們，審核後加進詞庫。不會傳送前後文或你在哪個 App 打字。可以在打字教學最後一頁或 App 的「一般」頁關掉。詳見隱私權政策。

選錯一次，那個字一直排前面？

在「輕注音」App 的「選字紀錄」刪掉那一筆，馬上恢復。

更新與解除安裝

macOS 會在背景下載並安裝新版，裝好後通知你（可以在 App 關閉「自動更新」）；Windows 有新版時會跳出通知，按「更新」就安裝。解除安裝：macOS 在 App 按「解除安裝…」再把 App 丟到垃圾桶；Windows 到設定 → 應用程式 → 輕注音 → 解除安裝。

Windows 有什麼限制？

Windows 10／11 的一般（x64）與 32 位元程式都能用。Arm 版 Windows 上以模擬執行的 x64 程式暫時還不支援（Arm 原生程式可以）。
