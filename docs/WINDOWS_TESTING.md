# 輕注音 Windows 版測試指南

給 Ino 在 Windows 電腦上試用 CI 產生的安裝檔。發現任何問題，記下「在哪個程式、做了什麼、預期／實際」，附上 log（見最後），貼給 Claude 即可。

## 1. 取得安裝檔

1. 打開 https://github.com/nvlznn/light-bopomofo/actions ，點最新一次 **CI**（綠色勾勾）。
2. 頁面最下方 **Artifacts** 有 **LightBopomofo-Setup**，下載後解壓縮得到 `LightBopomofo-Setup.exe`（需要登入 GitHub）。

## 2. 安裝

1. 執行 `LightBopomofo-Setup.exe`。第一版沒有程式碼簽署，會出現「Windows 已保護您的電腦」：按 **其他資訊 → 仍要執行**。
2. 允許「使用者帳戶控制」（要裝到 Program Files）。
3. 裝完勾選「開啟輕注音」：App 應該顯示「輕注音 0.x 可以使用了」。若顯示「還沒加入輸入法」，按「加入輸入法」。
4. 按 **Windows 鍵 + 空白鍵** 切到「輕注音」（或點工作列右下的語言圖示）。工作列應顯示「中」。

## 3. 基本打字（先在記事本）

| # | 操作 | 預期 |
|---|---|---|
| 1 | 打 `s` `c` `a`（ㄋㄏㄇ） | 游標處出現加底線的「ㄋㄏㄇ」，下方候選視窗第一個是「你好嗎」 |
| 2 | 按 Enter | 送出「你好嗎」，底線與候選視窗消失 |
| 3 | 打 ㄍㄗㄈㄈ（`e` `y` `z` `z`），按 → 移到「工作」，按 Enter | 送出「工作」，剩下 ㄈㄈ 繼續組字，第一個候選「方法」 |
| 4 | 組字中按 Shift + `,` | 先送出選中的候選，再打出「，」 |
| 5 | 組字中按 Backspace／Esc | 刪一個注音／清空 |
| 6 | 打 ㄇㄚˇ（`a` `8` `3`） | 第一個候選「馬」 |
| 6a | 打 ㄊㄧㄢ（`w` `u` `0`），按空白鍵 | 輸入區變成「ㄊㄧㄢˉ」（一聲），第一個候選「天」；再按空白鍵不會有反應 |
| 7 | 單按一下 Shift | 工作列「中」變「英」，之後打字直接是英文；再按一次切回 |
| 8 | 開 Caps Lock 打字 | 大寫英文；關掉恢復注音 |
| 9 | 組字中用滑鼠點文件別處 | 注音被換成第一個候選，不會留下注音符號 |
| 10 | 組字中按 Ctrl+C／Ctrl+V | 先送出，快捷鍵照常運作 |
| 11 | 同一句分兩段選（例如 ㄊㄑㄏㄏ 先選「天氣」再選「很好」），再打一次 ㄊㄑㄏㄏ | 第一個候選直接是「天氣很好」 |
| 12 | 打很多字、換個程式再打 | 在 A 程式學到的選擇，在 B 程式也有效 |

候選視窗：位置在游標下方（靠近螢幕底部時在上方）、深色模式下是深色、不同縮放比例（設定 → 顯示 → 縮放）的螢幕上字的大小合理。

## 4. 相容性（W5）

每個程式試：能打字、候選視窗位置對、Enter 送出、空白鍵打一聲、選前段、Backspace、Shift 切換。

記事本、Word、Excel、Chrome、Edge、Firefox、VS Code、Windows Terminal、檔案總管（重新命名、搜尋框）、**開始功能表搜尋**、**設定 App 的搜尋框**、Microsoft Store 程式（例如計算機以外的文字輸入程式）、LINE、Discord、Teams、Slack、以系統管理員身分執行的記事本、密碼欄位（系統會停用輸入法，確認不會出錯）。

## 5. App（開始功能表 →「輕注音」）

- 狀態正確；「開啟語言設定」會打開設定
- 選字紀錄：打過的字有出現、搜尋、點欄位標題排序、選取後按 Delete 或「刪除所選」、「全部清除…」
- 刪掉一筆後，回到記事本打同樣的注音，那個選擇不再排第一

## 6. 更新與解除安裝

- **更新**：在輕注音開著（有程式正在用）的情況下，執行新版安裝檔：不應要求重新開機；新開的程式用新版。
- **解除安裝**：設定 → 應用程式 → 輕注音 → 解除安裝。輸入法從清單消失；選字紀錄保留在 `%APPDATA%\LightBopomofo\`。

## 回報問題時附上 log

在檔案總管網址列輸入 `%LOCALAPPDATA%\LightBopomofo\logs`，把 `ime.log`（和 `ime.old.log`，如果有）傳給 Claude。log 只記錄事件與錯誤（例如輸入法啟用、詞庫載入、例外），**不記錄你打的字**。
