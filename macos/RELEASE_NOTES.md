**輕注音 7.1：修復 macOS 登入後的背景服務錯誤。**

- 修復部分電腦重新開機後，背景更新服務因啟動條件不符而顯示「輕注音意外結束」的問題。
- 首次開啟新版會移除舊背景服務，建立新的服務登記。
- 程式或背景設定更新後，等待舊登記移除完成再重新登記，避免沿用失效的啟動條件。
- 新增「修復背景服務」按鈕；開發副本不再覆蓋正式版的背景服務登記。

安裝後請從「應用程式」開啟輕注音一次，完成背景服務遷移。如 macOS 要求背景執行授權，請在「系統設定 → 一般 → 登入項目與延伸功能」允許輕注音。

本次僅發布 macOS 修正版，支援 macOS 13 以上、Apple Silicon 與 Intel，已完成 Developer ID 簽署與 Apple 公證。Windows 維持 [7.0](https://github.com/nvlznn/light-bopomofo/releases/tag/v7.0)。
